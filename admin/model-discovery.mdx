## Why this exists

PostGlider generates image API calls via the intent pipeline. Costs live in `operation_pricing` and are refreshed daily. Query current costs:

```sql
SELECT operation_name, credit_cost FROM operation_pricing ORDER BY operation_name;
```

The competitive moat comes from **one-pass identity**: a model that accepts a business owner's headshot AND knows specific equipment brand names (e.g., "Toro ProCore 648") in a single call collapses both API calls into one.

MuAPI's catalog contains 412 models as of June 2026. Running monthly sweeps against standardized prompts catches pricing changes and surfaces cheaper alternatives before they're needed — not after.

## Scripts

Two scripts live in `/scripts` (CommonJS, run from the repo root):

### model-discovery.cjs — monthly benchmark

Compares known production and candidate models. Run this first — it confirms existing costs haven't drifted and validates the current candidate roster.

```bash title="Terminal"
node scripts/model-discovery.cjs                        # generate + PDF
node scripts/model-discovery.cjs --pdf-only             # rebuild PDF from today's cached images
node scripts/model-discovery.cjs --pdf-only 2026-06-01  # rebuild from June 1 images
```

Output:
- `/tmp/model-discovery/images/` — generated images (`YYYY-MM-DD-slug.jpg`)
- `/tmp/model-discovery/report.pdf` — stakeholder PDF with cost delta vs last month
- `/tmp/model-discovery/cost-history.csv` — running log for month-over-month trending

### model-sweep.cjs — broad discovery

Tests top candidates across MuAPI's full 412-model catalog in 4 probe dimensions.

```bash title="Terminal"
node scripts/model-sweep.cjs                        # full sweep (~$3–5)
node scripts/model-sweep.cjs --probe=brand          # brand knowledge only (~$0.80)
node scripts/model-sweep.cjs --probe=scene          # non-equipment scene baseline (~$0.35)
node scripts/model-sweep.cjs --probe=identity       # one-pass identity composite (~$0.50)
node scripts/model-sweep.cjs --probe=video          # video value matrix (~$1.00)
node scripts/model-sweep.cjs --budget=3             # cap total spend at $3
node scripts/model-sweep.cjs --refresh-leaderboard  # Playwright scrape of artificialanalysis.ai
```

Output:
- `/tmp/model-sweep/{date}/report.pdf` — discovery PDF (this is the one to open)
- `/tmp/model-sweep/{date}/results.csv` — raw metrics for trending
- `/tmp/model-sweep/catalog.json` — MuAPI catalog snapshot

## Four probe dimensions

<Callout kind="info">
  Start with `--probe=brand` ($0.80). It answers the highest-value question and is the cheapest probe to run.
</Callout>

### Brand knowledge (t2i)

Each candidate is run with both a **generic** and a **specific** prompt. If the outputs look identical, the model doesn't have brand knowledge and has no advantage over the cheapest option.

| Prompt type | Example |
|---|---|
| Generic | "A professional landscaper aerating a lawn, golden hour" |
| Specific | "A professional landscaper operating a **Toro ProCore 648** commercial core aerator, soil plugs ejecting" |

Industries require different specificity levels:

| Industry tier | Prompt must contain |
|---|---|
| Equipment trades (landscaping, HVAC, plumbing) | Brand + model name (Toro ProCore 648, Lennox XC21) |
| Skilled trades (tattoo, cosmetology, welding) | Technique + tool (balayage with tinting brush) |
| Wellness / fitness (yoga, PT, chiro) | Named pose or apparatus (Warrior II on Manduka PRO mat) |
| Food service | Plating style + equipment (brunoise on plancha, carbon steel) |

<Callout kind="warning">
  Brand knowledge only activates when the prompt explicitly names the brand. PostGlider's LLM-generated `visual_direction` must inject this specificity from the business profile before NAICS-based model routing has any value. The brand probe validates whether that enrichment is working.
</Callout>

### Scene quality (t2i)

Baseline quality check for non-equipment service industries. Prompt: hairdresser applying balayage highlights in a modern salon. Answers: what is the cheapest model that produces a publish-ready result?

### One-pass identity composite (i2i)

**This is the moat test.** Each candidate receives the business owner's headshot reference photo plus a brand-specific scene prompt in a single API call. Success criteria (all three required):

1. Face of the reference person is recognizable
2. Named equipment ("Toro ProCore 648") appears correctly rendered
3. Output is publish-ready at social media display size

If any model passes all three, PostGlider can eliminate the separate scene generation call — saving $0.045 per image and one full generation latency cycle.

### Video value matrix (i2v)

Compares image-to-video candidates by quality/cost ratio, using [Artificial Analysis](https://artificialanalysis.ai/video/leaderboard/image-to-video) Elo scores as the quality reference. A scene image is auto-generated with `gpt-image-2` and uploaded to Supabase Storage before the video probe runs.

## API quick reference (MuAPI)

```
Base URL: https://api.muapi.ai
Auth: x-api-key: {MUAPI_API_KEY}   ← NOT Authorization: Bearer (403s on all POSTs)

GET  /api/v1/models                             → full 412-model catalog (no auth required)
GET  /api/v1/account/balance                    → { balance, currency, email }
POST /api/v1/{model-name}                       → { request_id, status: "processing", cost: { amount_usd } }
GET  /api/v1/predictions/{request_id}/result    → { status, outputs: ["https://cdn.muapi.ai/..."] }
POST /api/v1/models/{model-name}/estimate-cost  → estimated cost before submitting
```

**Critical field names:**
- `images_list: [url]` — NOT `image_url` — for all i2i models (nano-banana-2-edit, flux-pulid, etc.)
- `resolution: "4K"` — must be explicit; default is `1k` which is lower quality
- CDN URLs in `outputs[]` expire in ~2 minutes. Download immediately with `curl -A "Mozilla/5.0"`.
- Poll timeout: 150s for image, 180s for video (P90 image generation is ~114s)
