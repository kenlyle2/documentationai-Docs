## Reading the diagram

**Solid arrows (`→`)** — the primary user journey, in rough chronological order.

**Dotted arrows (`-.->`)** — background or side-effect flows: images landing in the vault, credits being deducted, emails firing, niche intelligence feeding Genie.

**Yellow nodes** — decision gates (website/GMB/Instagram choices, account age, Pilot eligibility, plan approval).

**Red node** — hard lock ("Pilot Mode not yet available").

**Green nodes** — terminal states (new visitor entry, pack exported).

**Blue subgraphs** — system/infrastructure concerns (Credits, Email, UserTour sync).

## What changed from the original (April 2026)

| Area | Old | New |
|---|---|---|
| Entry point | `/start` | `/free-trial` |
| Onboarding structure | Single flow, anon → account | Two phases: `/free-trial` (anon) → `/onboarding` (authenticated) |
| Data collection | Website → GMB → profile → generate | Website → GMB → Instagram → Business → Profile → Photo → Generate |
| Account claim | Inline at end of `/start` | AUTH step → redirects to `/onboarding` for completion |
| Specialization | Background only | Explicit `StepSpecialization` in `/onboarding` with NAICS/SIC picker |
| Niche intelligence | Classification only | Full pipeline: `classifyBusinessNiche` + `generateNicheAssist` + `generateServiceIntelligence` |
| Post-onboarding guidance | None | UserTour — 3 trait-triggered walkthroughs |
| GMB photos | Scored + imported during onboarding | Queued via `gmb_scout_jobs` during `/onboarding`, imported async |
| Publishing | UploadPost | Postforme (pre-approved OAuth, no Meta App Review) |

## Key drip gates

| Feature | Minimum tier | Account age |
|---|---|---|
| Pilot Mode (Antigravity Drawer) | Pro+ | ≥ 7 days (`pilot_eligible = true`) |
| Butler AI | Pro+ | Same drip as Pilot Mode |
| Weekly Architect | Pro+ | No age gate |
| Quick Visual (Ideogram) | Free | No gate |
| Genie themes | Free (1 credit) | No gate |
